Proyecto Retail – Preentrega SQL

Descripción

Este proyecto consiste en la creación de una base de datos para un comercio minorista, utilizando PostgreSQL.

El objetivo es organizar la información de clientes, productos y ventas, estableciendo relaciones entre las tablas y aplicando restricciones para garantizar la integridad de los datos.

Estructura de la base de datos

La base de datos retail_project contiene tres tablas:

clientes: almacena los datos de los clientes.

productos: registra los productos disponibles, sus precios y stock.

ventas: registra las ventas realizadas y relaciona clientes con productos.

Funcionalidades implementadas

Creación de tablas mediante instrucciones DDL.

Definición de claves primarias y foráneas.

Aplicación de restricciones CHECK, NOT NULL y UNIQUE.

Inserción de cinco registros iniciales por tabla.

Uso de transacciones con BEGIN y COMMIT.

Actualización de precios de productos electrónicos mediante UPDATE.

Eliminación de una venta de prueba mediante DELETE.

Tecnologías utilizadas

PostgreSQL

pgAdmin 4

SQL

Instrucciones de ejecución

Crear una base de datos llamada retail_project en PostgreSQL.

Abrir pgAdmin 4 y conectarse a esa base de datos.

Abrir el archivo retail_project.sql desde Query Tool.

Ejecutar el script completo una sola vez sobre la base vacía.
